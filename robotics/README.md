# Machine & Robotics — native SolidCraft Rust/egui integration

This adds an **in-process egui panel**, not a manifest-only/WASM plugin.
The code uses SolidCraft's own `SolveApp::run` commands for undoable joint,
inverse-kinematics, timeline, and collision operations.

## Windows: run through GitHub Actions

1. In this repository go to **Actions → Build SolidCraft Robotics (Windows)**.
2. Press **Run workflow**, select `feature/robotics-native-ui`.
3. If the build and test succeed, open that workflow run and download
   `SolidCraft-Robotics-Windows` from **Artifacts**.
4. Unzip and launch `SolidCraft-Robotics.exe`. It is an experimental build:
   preserve backups of your CAD files.

**The executable is generated by GitHub Actions, not attached to this repository.
No working .exe should be assumed until the workflow finishes successfully.**

## Build locally from the upstream SolidCraft source

```powershell
git clone https://github.com/tangency-labs/solidcraft.git
git clone -b feature/robotics-native-ui https://github.com/ivox80/solidcraft.git robotics-toolbox
py robotics-toolbox/robotics/apply_to_upstream.py solidcraft
cd solidcraft
cargo test -p solidcraft-ui-egui --lib robotics_toolbox
cargo build --release -p solidcraft
.\target\release\solidcraft.exe
```

Upstream's `Cargo.toml` specifies Rust 1.95+; native build dependencies
and target details are in upstream `docs/building.md`.

## Use inside SolidCraft

Open a design: **MACHINE & ROBOTICS** floats above the CAD viewport.
Toggle with **Ctrl+Shift+R**. When closed, a launcher appears at top-right.

- **Gelenke**: choose two assembly occurrences, either from the CAD Browser
  selection or by entering the occurrence names/IDs; specify world pivot and
  axis, then create a native joint. You can use SolidCraft's usual Joint command
  for graphical pivot/axis picking as an alternative.
- **Antrieb**: select a joint and move by degrees (revolute) or mm (slider).
- **Zielpunkt**: select an end-effector and an absolute world coordinate;
  call SolidCraft native `joint.reach` inverse kinematics.
- **Timeline**: make a keyed native motion study; inspect individual frames;
  run an interference check across the study.

Note that this prototype scrubs discrete frames; continuous native playback
remains available through SolidCraft's standard Motion Study dialog. This
source patch does not add a permanent workspace tab or a WASM plugin installer.

Validate collisions and constraints before any real robot actuation.
