# Machine & Robotics — native SolidCraft Rust/egui integration

This adds an **in-process egui panel**, not a manifest-only/WASM plugin.
The code uses SolidCraft's own `SolveApp::run` commands for undoable joint,
inverse-kinematics, timeline, and collision operations.

## Windows: run through GitHub Actions

1. In this repository go to **Actions → Build SolidCraft Robotics (Windows)**.
2. Press **Run workflow**, select `feature/robotics-native-ui`.
3. If the build and test succeed, open that workflow run and download
   `SolidCraft-Robotics-Windows` from **Artifacts**.
4. Unzip and launch `SolidCraft-Robotics.exe`. The artifact also contains
   `robot_arm_two_axes.sc`, an editable robot assembly with two revolute
   joints and a keyed motion study. Open it with **File → Open**.
5. This is an experimental build: preserve backups of your CAD files.

**The executable is generated by GitHub Actions, not attached to this repository.
No working .exe should be assumed until the workflow finishes successfully.**

## Build locally from the upstream SolidCraft source

```powershell
git clone https://github.com/tangency-labs/solidcraft.git
git clone -b feature/robotics-native-ui https://github.com/ivox80/solidcraft.git robotics-toolbox
py robotics-toolbox/robotics/apply_to_upstream.py solidcraft
cd solidcraft
cargo test -p solidcraft-ui-egui --lib robotics_toolbox
cargo build --release -p solidcraft
.\target\release\solidcraft.exe
```

Upstream's `Cargo.toml` specifies Rust 1.95+; native build dependencies
and target details are in upstream `docs/building.md`.

## Use inside SolidCraft

Open a design: **MACHINE & ROBOTICS** floats above the CAD viewport.
Toggle with **Ctrl+Shift+R**. When closed, a launcher appears at top-right.

- **Gelenke**: select two occurrence placements, faces or bodies in the CAD
  Browser/viewport and click **2 ausgewählte Instanzen übernehmen**. You can
  alternatively type occurrence names/IDs. Select a planar/cylindrical face or
  straight edge and click **Achse/Punkt von CAD-Fläche oder Kante** to get the
  pivot/axis. Curved/ambiguous edges deliberately fall back to manual picking.
  **Gelenk grafisch im 3D erstellen** launches SolidCraft's native graphical
  Joint dialog, where native face/edge snaps are available.
- **Antrieb**: select a joint and move by degrees (revolute) or mm (slider).
  Copy its current value with **Istwert**. A configurable slider can optionally
  update the pose live; many live updates can create extra undo steps. The native
  Drive Joint dialog is available as a fallback.
- **Zielpunkt**: select an end-effector and an absolute world coordinate;
  call SolidCraft native `joint.reach` inverse kinematics.
- **Timeline**: create or update a keyed motion study (an existing name updates
  its saved keyframes rather than creating a duplicate); inspect individual frames
  and run an interference check. A truncated collision analysis is explicitly
  reported as incomplete, never as collision-free.

Note that this prototype scrubs discrete frames; continuous native playback
remains available through SolidCraft's standard Motion Study dialog. This
source patch does not add a permanent workspace tab or a WASM plugin installer.

Validate collisions and constraints before any real robot actuation.

## Testing checklist

1. Open `robot_arm_two_axes.sc` in the new SolidCraft executable.
2. Open **Machine & Robotics → Antrieb**, click **Neu laden**, choose `Shoulder`.
3. Press **Istwert**, drag the slider, then **Gelenk bewegen** and check motion.
4. Switch to **Timeline**, choose `Robot Arm Cycle`, set frame 50, play the frame.
5. Select a straight edge or cylindrical face in the viewport and use the
   geometry-to-axis button, or open the native graphical Joint dialog.
6. Run the motion interference check and inspect its status (including truncation).

A green CI build verifies compile/tests plus generation of the CAD fixture.
A visual mouse-and-window acceptance test still requires running the executable.
